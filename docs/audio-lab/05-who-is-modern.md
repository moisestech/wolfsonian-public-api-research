## Fixed script — ElevenLabs multi-speaker / editable audio master
Each turn below is an **original fictional line written for this experiment**. Do not claim the actual objects spoke or the museum approved these lines. Delivery directions are optional performance cues, not part of the archival record.

01. **Catalogue, Machine Age Exposition** _(opening)_: Machine Age. Two words and suddenly I've named a whole era.

02. **Vase with lid, Mappemonde [Globe]** _(dry)_: That is a rather efficient label.

03. **Catalogue, Machine Age Exposition** _(quick)_: You sound unconvinced.

04. **Vase with lid, Mappemonde [Globe]** _(challenge)_: My record has different names for form, décor and decoration. A period label doesn't tell you who did which part.

05. **Catalogue, Machine Age Exposition** _(beat)_: So I'm a bad catalogue?

06. **Vase with lid, Mappemonde [Globe]** _(soften)_: No. You're a beginning. A label is useful when it leads somewhere.

07. **Catalogue, Machine Age Exposition** _(self_correct)_: [soft laugh] And dangerous when it stops the search.

08. **Vase with lid, Mappemonde [Globe]** _(end)_: Exactly. Open the page. Look for the names.
