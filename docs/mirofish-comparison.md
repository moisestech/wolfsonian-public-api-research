# MiroFish comparison (conceptual only)

## Borrowed as architecture ideas

- Seed corpus
- Graph construction
- Bounded agent roles
- Simulation rounds
- Emergent interaction among claims
- Report / analysis layer (here: residency questions + object-request candidates)

## Intentionally rejected

- Prediction framing
- Social-media metaphors (Twitter/Reddit)
- Mass opinion / likes / follows / trending mechanics
- Treating emergence as truth
- AGPL source incorporation into this MIT repository

**No MiroFish source code is incorporated.** See also [`experiments/mirofish/README.md`](../experiments/mirofish/README.md) for how to run MiroFish separately as a benchmark.

## Future note

Persistent agent frameworks such as OASIS (Apache-2.0) may be evaluated later. Research Demo 001 does not require them.
