# Future simulation tech (research backlog)

This note captures a **later** visualization ambition for Archive Dreams in Public: a Civilization-like / crowd-sim tableau where interpretive agents feel present in space—walking, gathering, and “speaking” near records.

**Not for the current Luna share.** Research Demo 001 stays a deterministic, static, provenance-first instrument.

## What must stay true

- Deterministic authored rounds remain the **evaluation baseline** for any generative agents.
- Source packets and interpretation layers stay separated.
- `FABRICATION_TEST` never reads as catalog fact.
- No museum photography without clarified rights.
- No AGPL MiroFish code in this MIT repo (conceptual benchmark only).

## Candidate technology path (later)

| Layer | Options to evaluate | Role |
|---|---|---|
| Motion / presence | SVG + GSAP, Canvas 2D, PixiJS, or Three.js | Agent locomotion and camera framing |
| Layout | Force-directed or authored waypoints on a 2:1 tableau | Keep panoramic research-instrument tone |
| Speech | Scripted bubbles from existing round JSON first | LLM voice only after baseline claims stay auditable |
| Audio | Optional spatial/ambient beds | Atmosphere—not narration of unverified facts |
| Multi-agent runners | OASIS (Apache-2.0) out of tree | Level 3 evaluation—not vendored here |

## Suggested build order (when returning)

1. Keep current claim inspector + Residency as the truth UI.
2. Add **visual presence** of the six agents as sprites/tokens bound to the same claim data (no new claims).
3. Add locomotion along authored paths between selected records.
4. Only then consider generative dialogue, measured against the five deterministic rounds.

## Explicit non-goals now

- Live crowd simulation in the public demo
- Replacing Residency with a game loop
- Turning the museum into a prediction engine
