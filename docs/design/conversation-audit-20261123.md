# Archive Society room audit

November 23, 2026 · Main at [`c598f70`](https://github.com/moisestech/wolfsonian-public-api-research/commit/c598f701df5380b8f4aea0488535793d8e1095ef)

Baseline is the 40 authored conversations on main after PR #100, commit c598f70. It includes 20 curated tag edges and 20 proposed pairings. The public assembly admits 36 pairs under its current tag and record gates. Four rows are working-set only. This is a written review of the delivered script and room behavior. Live listening, image inspection for flagged claims, and editorial or museum sign-off are separate.

Nine object transcripts need revision, twelve need polish, and nineteen are strong enough to retain for a first read-aloud. These are editorial judgments about the object dialogue. The listener question on main is still the same persona hook across all rooms. All forty have a listener-writing task under this standard, including the nineteen retained scripts.

Draft PR #97 supplies alternative object text in thirty out of forty rooms, including all seven openings revised in #100. Check by scene ID and retain the revised opening questions during reconciliation. Compare one transcript at a time and import room-specific listener drafts separately. Use the source and speech checks before borrowing a line or generating audio.

The production index records ten pairs with a museum source locator for both objects and thirty needing at least one more source. This is an independent NotebookLM source status. A room can be interesting to read with a source hold, and a pair with two locators still needs review.

Start with Radio × Television, Futurama spread × Harlem invitation, East Indies poster × 1939 A.D., and Pirelli heels × Biennial. They test domestic listening, object-versus-exhibit identity, a serious political exchange, and a commercial pair that already works. Read Making the Engine × Grind Safely first as the control. Use the same room question and two listener choices in each review.
