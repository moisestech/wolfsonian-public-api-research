## How to review

Compare the big portraits against the four supplied mask studies for **consistent crown, cheek, eye, nose, circular aperture cutouts, optical margins and monochrome line weights**. The shared identity icon at left is already stable in code, but a consistent icon is not the same as a coherent set of large face illustrations. The eight v4 portraits need approval/redesign and the final eleven expressive masks will need separate full and optically simplified compact exports.
