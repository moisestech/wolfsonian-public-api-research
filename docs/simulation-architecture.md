# Simulation architecture (Research Demo 001)

## Layers (never merge)

| Layer | Path | Contents |
|---|---|---|
| Source | `data/public/objects/` | What public Wolfsonian sources state |
| Interpretation | `data/research/interpretations/` | Entities, pressures, open questions |
| Simulation | `data/research/simulations/` | Deterministic agent rounds |
| Research questions / requests | `data/research/object-request-candidates/` | Residency planning aid |

Compiled static demo assets live under `demo/data/` (generated by `npm run build:demo`). Those files are **intentionally committed** so static hosts can serve without a private compile step; edit Layer A/B sources, then regenerate—do not hand-author `demo/data` as truth.

## Packet establishment fields

Public objects may list:

- `established_in_public_packet` — fields grounded in the cited public sources for this packet
- `not_established_in_public_packet` — questions the **current representation** cannot answer

These describe limits of the packet, not claims that museum staff lack knowledge.

## Claim types

- `SOURCE_SUPPORTED` — grounded in cited seed fields
- `INFERENCE` — interpretive hypothesis beyond the field text
- `UNCERTAIN` — explicitly unresolved
- `FABRICATION_TEST` — adversarial plausible fill; never presented as fact

## Interaction types

`AGREES_WITH` · `CONTRADICTS` · `GROUNDED_BY` · `CHALLENGES` · `REQUIRES_ONSITE_RESEARCH`

## Agents

Archivist, Worker, Futurist, Mourner, Propagandist, Counterfeit (methodological adversary), and The Museum (coherence-seeking institutional voice in rounds only).

## Capacity

Schema supports ~30 records. Demo 001 ships a **featured set of 6**. Extras may remain in `data/public/objects/` without loading into the default graph.

## Non-goals

No live LLM, no MiroFish/AGPL code, no Twitter/Reddit metaphors, no prediction branding, no collection photography without clarified rights.
