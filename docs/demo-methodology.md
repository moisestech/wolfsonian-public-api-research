# Demo methodology — Research Demo 001

## What this demo proves

1. Public archival records can become computational material.
2. Bounded interpretive agents can construct competing readings from that material.
3. Disagreements generate concrete questions about which physical objects to request for onsite research.

## Method chain

```text
SOURCE RECORD
→ INTERPRETATION
→ SIMULATION ROUND
→ AGREEMENT / CONTRADICTION
→ UNCERTAINTY
→ ONSITE QUESTION
→ OBJECT-REQUEST CANDIDATE
```

## What is deterministic on purpose

Rounds are authored JSON, not live LLM output. That keeps every claim inspectable and provides a baseline for later generative experiments.

## What is not claimed

- Historical truth determination
- Calibrated social simulation
- Prediction of visitor opinion
- Official Wolfsonian product status

## Rights

No museum collection photography is republished. Diagrammatic SVGs are original schematic representations.
